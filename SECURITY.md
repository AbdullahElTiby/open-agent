# Security Policy

Open Agent launches local agent CLIs that can read and edit files and run commands, so security reports matter.

## Reporting a vulnerability

Please **do not** open a public issue. Instead, use GitHub's [private vulnerability reporting](../../security/advisories/new) or email abdullaheltiby@gmail.com.

Include a description, steps to reproduce, and the impact. You'll get a response as soon as possible, and credit in the fix if you'd like.

## Supported versions

Only the latest release on `main` receives security fixes.
